# ysmstep 0.5.2 — 视角摇晃跟着节拍了

0.5.2 把镜头也接到同一个钟上：打开后，视角摇晃的相位由模型动画节拍驱动，和脚步声同步。
以前是声音跟着模型走、镜头还按走过的距离晃，两套节奏会打架。

## 新增

- **视角摇晃同步（可选，默认原版）**
  - `/ysmstep bob`：在「原版 / 跟动画节拍」之间切换
  - `/ysmstep bobscale <倍率>`：摇晃幅度，0–2（默认 1.0，觉得晕就调小）
  - 只对本地玩家生效，第三人称看别人仍是原版
  - 做法：不接管 `bobView` 的数学，只把 `walkDist / walkDistO / bob / oBob` 换成节拍器换算的值，
    所以和其它相机类模组的注入不冲突

## 修正

- 摇晃相位换算：一步 = `walkDist +1.0`（按 `Entity#move` 的实际比例），
  开发中曾写成 0.6，会让摇晃周期比脚步慢一倍。

## 安装

- 客户端必需，服务端可选（想要联机同步档案时，和客户端放同一个 jar）
- Minecraft 1.21.1 / NeoForge 21.1+
- 下载附件 `ysmstep-0.5.2.jar` 放进 `mods/`

## 已知限制

- 视角摇晃默认关：它改的是镜头不是声音，和相机类模组叠加的观感因人而异
- 周期仍需逐模型校准（YSM 2.6.5 不暴露动画时长，模型文件加密）
- 与 Presence Footsteps 的兼容按类名挂载，PF 大改结构时会在 `/ysmstep status` 显示 `[PF闸门未触发]`

完整命令表、校准方法和原理见 [README](https://github.com/Elisolia/ysmstep#readme)。
