## 二、简介正文（可直接粘贴，粘完用编辑器把几处标题设为小标题）

```
ysmstep 让 Yes Steve Model 的模型脚步声踩在模型自己的动画节拍上。

[h1=它解决什么问题]
YSM 的走路动画按「动画时间」循环，一个循环的时长是固定的（默认模型走路 1 秒、跑步 0.667 秒）；
而原版脚步声是「按走过的距离」触发的（每 0.6 格一声，走路约 0.39 秒一声）。
两个钟不一样，所以越走越错——多数模型会出现走两步、响三声，脚落地的瞬间和声音对不上。

ysmstep 把脚步声改成跟着动画周期走：压掉原版那套距离触发的脚步，改用一个按动画周期推进的节拍器发声。

[h1=功能]
· 动画周期节拍器：一步 = 半个动画周期，跑步/潜行各有独立系数。
· 空中不打断相位：跳跃、过坎、落地抖动不会把拍子拽偏。
· 按姿势换音色：走路 / 跑步 / 潜行可以分别设为
    step（踩地声）、none（不出声）、wind（鞘翅风声）、flap（拍翼）、soft（软脚），
    跑步时整个人悬空的模型用 none 或 wind 比硬配踩地更自然。
· 兼容 Presence Footsteps (NeoForge)：装了它的时候，ysmstep 只决定「什么时候踩」，
    音色、材质关联、左右脚交替、上下楼分档仍由 Presence Footsteps 决定。
· 联机同步：校准好的参数可以上传到服务端存档并广播给其他玩家，
    别人就能按你模型的参数听到你的脚步（服务端需装同一个 jar；不装也能正常游戏）。

[h1=怎么用]
1. 进入游戏，在「选项 → 控制 → YSM 脚步同步」里给「触拍」键绑一个按键。
2. 切第三人称，盯着模型走路，跟着它的落地连点 4 下以上，即可自动算出动画周期。
3. 如果声音稳定地早/晚半步（但不会越走越偏），用 /ysmstep offset +0.05 微调相位。
4. 跑步时整个人悬空的模型：/ysmstep mode run none（或 wind）。

[h1=常用命令]
/ysmstep                       查看状态
/ysmstep on | off              开关（关掉即恢复原版脚步声）
/ysmstep cycle <秒>            走路动画周期（0.2–4.0）
/ysmstep offset <秒>           相位偏移（-1.0–1.0）
/ysmstep mode <walk|run|sneak> <step|none|wind|flap|soft>
/ysmstep tap [step|cycle]      触拍一拍代表什么
/ysmstep test                  立刻播一声，验证声音通路
/ysmstep hud                   常驻状态面板
/ysmstep share [模型名]        把校准上传到服务端
/ysmstep apply                 套用服务器里同模型名的校准
全部命令在游戏内输入 /ysmstep 可查看补全。

[h1=注意事项]
· 动画周期需要按模型手动校准一次：YSM 没有暴露动画周期接口，模型文件（.ysm）内容加密，
  读不到周期和相位，只能用触拍采样或手动调数值。
· Presence Footsteps 更新后兼容层可能失效，此时游戏内状态会提示「PF闸门未触发」，
  可用 /ysmstep pf 退回原版音色，不会崩溃。
· 联机时相位由各客户端自行计时，存在几十毫秒的差异，不是严格同步。
· 本模组只管走路 / 跑步 / 潜行；游泳、飞行、坐骑、鞘翅保持原版行为。
· 纯客户端改动，不修改存档、不修改模型文件、不包含 YSM 的任何资源，卸载即恢复原状。

[h1=支持版本]
Minecraft 1.21.1 / NeoForge 21.1 及以上。
不装 Yes Steve Model 也能运行（但没有使用意义）。

[h1=许可]
MIT。源码与问题反馈：https://github.com/Elisolia/ysmstep
本项目为第三方非官方模组，与「是，史蒂夫模型」及 Presence Footsteps 的作者无隶属关系。
```

## 三、投稿时容易被打回的四个点（都已覆盖，自查用）

1. **要有官方来源**：GitHub + Modrinth 都有 → ✔
