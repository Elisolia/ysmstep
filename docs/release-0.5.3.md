# ysmstep 0.5.3

**这次的改动：有了一个真正的设置界面，不用再靠命令调参。**

## 新增：设置面板（默认 `Ctrl + Y`）

- 左边 3D 预览，可以让模型 **走 / 跑 / 停**，直接看她落脚在哪一刻
  - 左键拖 = 平移，右键拖 = 旋转，滚轮 = 缩放（0.3×–4×）
  - 预览裁切在框内，放大不会糊到右边按钮上
- 左下 **周期与相位条**：一根横轴 = 一个循环，两根竖刻度 = 两次落地，黄色播放头在走，
  响一声整条闪一下。对齐好不好一眼就能看出来。
- 右边分「发声 / 时序 / 其他」三组。

## 新增：面板里直接听

- 选「走 / 跑」时按**当前周期和相位**真实发声，边听边调。
- 点「触拍校准」会停一拍半、只响你按的那一下；连点 4 下自动算周期，按钮上显示 `0/4 … 4/4`。
- 装了 Presence Footsteps 且开着对接时，优先用它的音色踩这一下。

## 新增：滚轮调值

鼠标悬在滑条上直接滚，不用按住拖：

| 操作 | 步长 |
|---|---|
| 直接滚 | 0.1 |
| Shift + 滚 | ×10 |
| Ctrl + 滚 | ×0.1 |
| Alt + 滚（仅相位） | ×0.01 |

每个滑条右边还有一键还原（周期回 1.00s、相位回 0、音量回 ×1.00）。

## 改进

- 发声方式（踩地 / 不出声 / 风声 / 拍翅 / 软脚）改成**下拉列表**，每一档都写了适用场合，
  不用再记 `step` `none` `wind` 这些词。
- 面板有**夜间 / 昼间两种主题**（右下角切换，默认夜间，记进配置）。
- 某个姿势的发声方式不是 `step` 时（飞行模型、轮滑模型），**视角摇晃自动归零**，
  不会出现「没踩地却还在晃」。

## 修复

- 游戏内模组列表显示的版本号一直是旧的（`mods.toml` 里写死了），现在跟着 jar 版本走。
- 补上模组图标。

## 加载器

- **NeoForge**：`ysmstep-0.5.3-neoforge.jar`
- **Fabric**：`ysmstep-0.5.3-fabric.jar`

功能一致，按你的加载器装**其中一个**。Fabric 端因为平台没有修饰键那一层，面板键在
「控制」里只显示 `Y`：**保持默认键位时**要按住 Ctrl，自己改成别的键之后就不用按了。

## 升级提示

这是一个纯客户端模组，直接替换 jar 即可。配置沿用 `config/ysmstep-client.json`，
校准值不会丢；新增的 `theme` 字段默认夜间。
